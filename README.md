This is an entrance learning project for AI course.  It consists of:
1. Basice concept of AI - a big picture of AI;
2. Context Engineering and AI Agent;
3. Understand the LLM;

# How to run this project
1. Install anaconda (https://www.anaconda.com/docs/getting-started/anaconda/install/linux-install#anaconda-navigator)
2. Run the anaconda: 
```bash

anaconda-navigator

```
3. launch Jupyter Notebook to start the Jupyter Server(external) and configure the kernel by using the token generated by the server.
